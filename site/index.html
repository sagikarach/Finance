Mac

טוען…
הורדה ל-Mac
איך מתקינים?
  1. פתח את הקובץ Finance-mac.zip שהורד.
  2. גרור את Finance לתיקיית Applications.
  3. בפתיחה הראשונה: לחיצה ימנית על האפליקציה ← Open ← Open.
    (אם מופיע "לא ניתן לפתוח": הגדרות מערכת ← פרטיות ואבטחה ← Open Anyway)

Windows

טוען…
הורדה ל-Windows
איך מתקינים?
  1. חלץ את הקובץ שהורד.
  2. הפעל את Finance.exe.
  3. אם מופיעה אזהרת SmartScreen: More info ← Run anyway.

Android

טוען…
הורדה ל-Android
או סרוק עם הטלפון כדי להוריד
איך מתקינים?
  1. הורד את הקובץ app-release.apk בטלפון.
  2. פתח אותו. אם מתבקש — אשר התקנה ממקורות לא ידועים עבור הדפדפן.
  3. לחץ התקן.

אחרי ההתקנה

  1. פתח את האפליקציה והזן אימייל וסיסמה.
  2. לחץ צור חשבון חדש — התקציב שלך מוכן מיד, בלי שום הגדרה.
  3. באפליקציה השנייה (מחשב / טלפון) פשוט התחבר עם אותו אימייל — הנתונים יופיעו שם.
רוצה לנהל תקציב משותף עם בן/בת הזוג? קוד השיתוף נמצא בהגדרות. בהרשמה הם בוחרים "יש לי קוד שיתוף" ומזינים אותו.
