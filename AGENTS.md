# AGENTS.md

Guidance for AI agents (and humans) working in this repo.

## What this is

**Finance** — a personal-finance manager with two clients on a shared Firebase backend:

- **Desktop** (`finance/`, entry `main.py`) — a **PySide6/Qt** app, Python 3.10+ (3.11 recommended). The primary client. UI is **Hebrew / right-to-left**; user-facing strings are Hebrew literals in the code.
- **Mobile** (`finance_mobile/`) — a Flutter MVP (Firebase Auth + Firestore). Its Firestore document shape must stay in sync with the desktop (see `finance_mobile/README.md`).

Domain: bank/budget/savings accounts (savings has sub-savings), bank movements (income/expense × MONTHLY/YEARLY/ONE_TIME), installment plans, one-time events, monthly/yearly reports, notifications.

## Setup & run (desktop)

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Dependencies: `PySide6`, `platformdirs`, `PyNaCl`, `certifi` (see `requirements.txt`).

## Architecture (desktop)

- **`finance/qt.py`** — Qt compatibility shim: prefers PySide6, falls back to PyQt6. **Always import Qt classes from `..qt`, never from `PySide6` directly.**
- **`finance/app.py` → `run_app()`** — entrypoint: icon/theme, optional lock screen (`LockDialog`), best-effort Ollama startup, then `MainWindow`.
- **`finance/ui/main_window.py` + `ui/router.py`** — `Router` over a `QStackedWidget`; pages are built lazily via factories. Startup fires a background pull-sync from Firebase. `Router.reset()` recreates all pages after a user/workspace switch.
- **`finance/pages/base_page.py`** — `BasePage(QWidget)` is the heavyweight base every page extends: builds the header (notifications bell, sync button, theme toggle), sidebar, and add-movement buttons, and owns the providers/services. Subclasses implement `_build_content(layout)`.
- **`finance/models/`** — frozen `@dataclass` domain types (`accounts.py`, `bank_movement.py`), `*_service.py` business logic, and the `firebase_*` sync modules.
- **`finance/data/`** — provider layer. `JsonFile*Provider` classes read/write **per-workspace JSON files** with atomic writes (`.tmp` + `os.replace` + `fsync`).
- **`finance/widgets/`** — reusable Qt widgets (charts, sidebar, tables, pickers). **`finance/styles/`** — QSS light/dark themes. **`finance/utils/`** — `app_paths`, `icons`, `formatting`, `updater`.

## Data & sync

- User data lives **outside** the app bundle so updates don't wipe it. macOS: `~/Library/Application Support/Finance/` (accounts under `accounts/`). Legacy `./data/accounts/*.json` is migrated on first launch.
- Files are scoped per workspace/uid, e.g. `bank_accounts_{workspace_id}.json`, `bank_movements_{key}.json`. The key comes from `current_firebase_workspace_id()` (fallback uid) in `models/firebase_session.py`.
- Sync orchestrator: `models/firebase_movements_sync.py` `FirebaseMovementsSyncService.sync_now(allow_push=...)` (guarded by a class-level lock). Each `firebase_sync_*.py` module owns one slice (movements, categories, events, installments, notifications, accounts meta, action history, ML seed). `BasePage._GLOBAL_SYNCING` drives the hourglass UI state.
- Firestore movement doc shape (keep in sync with mobile): `id, amount (+income/-expense), date YYYY-MM-DD, account_name, category, type (MONTHLY|YEARLY|ONE_TIME), description?, event_id?, deleted`.

## AI / classification

- `models/movement_classifier.py` `SimilarityBasedClassifier` — local, offline categorizer; training file rebuilt by `models/workspace_ml_trainer.py` after each sync.
- `models/gemini_classifier.py` — Google Gemini classifier. API key in macOS Keychain (`models/keychain_passwords.py`, account `gemini_api_key`); ordered model fallback list; handles 429 quota/retryDelay; confidence threshold 0.85.
- Charts show a math/AI savings-balance forecast.
- `app.py._ensure_ollama_running()` best-effort starts a local Ollama server (port 11434) if installed.

## Conventions

- **Defensive style**: nearly every Qt call is wrapped in `try/except Exception: pass`. Match this idiom — failures in UI glue should not crash the app.
- **Hebrew RTL**: user-facing strings are Hebrew literals; dialogs set `Qt.LayoutDirection.RightToLeft`. Keep new UI text Hebrew and RTL-aware.
- `from __future__ import annotations` at the top of modules; type hints throughout (`py.typed` marker present).
- Import Qt only via `finance/qt.py`.
- Never commit `finance/firebase_defaults_local.py` (gitignored local credentials).
- Code-review findings are tracked in `CODE_REVIEW.md`.
